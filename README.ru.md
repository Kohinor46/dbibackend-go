# DBI Backend (Go)

[English](README.md) | **Русский** | [Español](README.es.md) | [Italiano](README.it.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Português](README.pt.md) | [中文](README.zh.md) | [日本語](README.ja.md) | [हिन्दी](README.hi.md) | [العربية](README.ar.md)

Приложение для компьютера, которое устанавливает игры на Nintendo Switch с [DBI](https://github.com/rashevskyv/dbi) по USB. Выберите папку с файлами `.nsp` / `.nsz` / `.xci`, подключите Switch и устанавливайте.

Это переписанный на Go [lunixoid/dbibackend](https://github.com/lunixoid/dbibackend) (скрипт на Python): с графическим интерфейсом, готовыми сборками для macOS и Windows и без необходимости ставить Python или libusb.

![DBI Backend](docs/screenshot.png)

## Возможности

- **Графический интерфейс**: выбор папки (Finder, Проводник или перетаскивание), список найденных файлов с размерами, статус подключения, индикатор прогресса со скоростью передачи и журнал.
- **Без перезапусков**: после завершения работы DBI приложение снова ждёт Switch. Последняя папка запоминается, а сервер запускается автоматически при старте.
- **11 языков**: английский, русский, испанский, итальянский, немецкий, французский, португальский, китайский, японский, хинди и арабский. Язык берётся из системы, его можно сменить в окне.
- **Встроенная установка драйвера для Windows**: если приложение видит Switch без драйвера, оно предлагает его установить. Это заменяет ручной шаг с Zadig (см. ниже).
- **Файлы по MTP в macOS и Linux**: просмотр хранилищ Switch, загрузка, скачивание и удаление файлов без Android File Transfer (см. ниже).
- **Режим командной строки** (`-cli`), работающий как исходный скрипт, — для автоматизации.
- **Безопаснее оригинала**: Switch может запрашивать файлы только из выбранной папки.

## Использование

1. Запустите приложение и выберите папку с играми. Вложенные папки тоже учитываются.
2. На Switch откройте DBI и выберите **Install title from USB**.
3. Подключите Switch к компьютеру USB-кабелем. Статус сменится на **Подключено**.
4. Выберите файлы в DBI и установите их. Прогресс и скорость отображаются внизу окна.

## Windows: USB-драйвер

В Windows приложение может работать со Switch только через драйвер WinUSB. Раньше его приходилось ставить вручную через [Zadig](https://zadig.akeo.ie/).

Теперь приложение делает это само. Увидев Switch без драйвера, оно покажет запрос: нажмите **Установить** и подтвердите запрос прав администратора Windows. Кнопкой **Установить USB-драйвер** в окне можно воспользоваться и в любой момент. Switch должен быть подключён, а DBI — находиться в режиме **Install title from USB**.

Как это работает: приложение назначает устройству драйвер WinUSB, который входит в состав Windows и подписан Microsoft (то же самое, что **Обновить драйвер → Выбрать драйвер из списка доступных драйверов на компьютере → WinUsb Device** в Диспетчере устройств). Никаких сертификатов в систему не добавляется, и всё работает при включённом Интеллектуальном управлении приложениями (Smart App Control).

## Файлы по MTP (macOS и Linux)

В macOS нет встроенной поддержки MTP, поэтому Switch не появляется в Finder, когда DBI запускает MTP-респондер, а Android File Transfer, привычный обходной путь, больше не обновляется. Его заменяет вкладка **Файлы (MTP)**:

1. На Switch откройте DBI и выберите **Run MTP responder**, затем подключите кабель.
2. В приложении откройте вкладку **Файлы (MTP)** и нажмите **Подключить**.
3. Выберите хранилище (SD-карта, NAND, цели установки, сохранения и т. д.), открывайте папки и загружайте файлы кнопкой **Загрузить файлы…** или перетаскиванием в окно. Также можно скачивать и удалять файлы и создавать папки.

Чтобы установить игру, загрузите её в хранилище, в названии которого есть «install»: DBI устанавливает её по мере получения. Файлы больше 4 ГБ поддерживаются.

![Файлы (MTP)](docs/screenshot-mtp.png)

**«Switch занят другой программой».** В macOS системная служба камер (`ptpcamerad`) захватывает MTP-устройства сразу после подключения. Нажмите **Освободить устройство**: приложение остановит службу и займёт Switch, а macOS сама снова запустит службу, когда она понадобится. Android File Transfer тоже удерживает устройство, поэтому сначала закройте его.

В Windows вкладка скрыта: Проводник и так показывает Switch в режиме MTP.

## Linux

Чтобы открыть доступ к Switch без root, установите правило udev (оно действует в обоих режимах: установка по USB и MTP):

```bash
sudo cp data/linux/99-dbibackend.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
```

Если вкладка **Файлы (MTP)** сообщает, что Switch занят другой программой, возможно, рабочее окружение само смонтировало его (gvfs): отмонтируйте его в файловом менеджере.

## Скорость передачи

Скорость упирается в основном в Switch, а не в компьютер:

- По **USB 2.0** потолок — около **40 МБ/с**. На несжатых файлах `.nsp` / `.xci` приложение держит шину занятой примерно 80% времени и выходит в среднем на 32 МБ/с.
- **Файлы `.nsz`** устанавливаются примерно втрое медленнее: Switch сам распаковывает каждый блок.
- DBI запрашивает данные кусками до 1 МБ и просит следующий только после обработки предыдущего. Компьютер не может это ускорить.

В конце каждой сессии в журнале появляется строка `Session stats`:

| Поле | Значение |
|---|---|
| `usb_MB/s` | Скорость во время отправки данных |
| `avg_MB/s` | Средняя скорость от первого запроса до последнего |
| `time_data` / `time_handshake` / `waiting_for_switch` | Доля времени на отправку данных, обмен по протоколу и ожидание Switch |
| `active` / `idle` | Время установки и время простоя до и после неё |

Если `waiting_for_switch` велико, узкое место — Switch (скорость записи на microSD, распаковка NSZ). Если включена **Отладка**, журнал показывает каждый запрос DBI с его размером и скоростью.

## Режим командной строки

```bash
dbibackend -cli ~/Switch          # wait for the Switch, serve one session, exit
dbibackend -cli -debug ~/Switch   # the same with a detailed log
dbibackend ~/Switch               # open the window with this folder
dbibackend -install-driver        # Windows: install the WinUSB driver for the connected Switch
```

В macOS сервер может запускаться автоматически при подключении Switch: поправьте путь в `data/darwin/com.dbibackend.usb.agent.plist` и скопируйте файл в `~/Library/LaunchAgents/`.

## Сборка

Нужны Go 1.25+ и компилятор C (cgo требуется для libusb и Fyne).

```bash
# macOS
brew install libusb pkg-config
# Debian/Ubuntu (plus the Fyne dependencies: https://docs.fyne.io/started/)
sudo apt install libusb-1.0-0-dev pkg-config

make build        # ./dbibackend for the current system
make test         # tests
make release      # dist/DBI Backend.app and dist/DBI Backend.exe
```

`make release` запускается на macOS. Он собирает libusb из исходников и линкует её статически, так что результату не нужно ничего устанавливать. Для сборки под Windows дополнительно нужны `brew install mingw-w64` и утилита `fyne` (`go install fyne.io/tools/cmd/fyne@latest`).

## Структура проекта

| Пакет | Назначение |
|---|---|
| `dbi` | Протокол DBI0 (LIST / FILE_RANGE / EXIT), сканирование папки, статистика сессии |
| `usbconn` | Открытие Switch через libusb (gousb) в режимах установки по USB и MTP, bulk-передачи |
| `mtp` | MTP-клиент (PTP поверх USB): хранилища, папки, загрузка и скачивание, файлы больше 4 ГБ |
| `gui` | Интерфейс на Fyne |
| `i18n` | Переводы (`i18n/locales/*.json`) |
| `winusb` | Установка WinUSB в Windows (SetupAPI) |
| `cmd/winusb-helper` | Нативный помощник для ARM64 Windows для установки драйвера |

Чтобы добавить или исправить перевод, отредактируйте `i18n/locales/<code>.json`. `go test ./i18n/` проверяет, что во всех языках есть все ключи.

## Отличия от оригинала

- Switch может запрашивать файлы только из выбранной папки. Оригинал открывал любой путь, присланный устройством.
- Исправлен фильтр расширений: оригинал сопоставлял `nsz` без точки.
- Если в разных вложенных папках есть файлы с одинаковым именем, используется первый найденный (DBI видит только имена файлов).
